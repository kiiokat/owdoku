# Hero portraits

The game shows Blizzard's official hero portraits from
[overwatch.blizzard.com/en-us/heroes](https://overwatch.blizzard.com/en-us/heroes/).
They are Blizzard's artwork, so they are not included in this repository.

To download them into this folder on Windows, run from the repository root:

```
powershell -ExecutionPolicy Bypass -File .\tools\get-hero-portraits.ps1
```

Without the portraits the game still works; player cards show initials instead.
